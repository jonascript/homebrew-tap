# Jonascript Tap

## How do I install these formulae?

`brew install jonascript/tap/<formula>`

Or `brew tap jonascript/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jonascript/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
